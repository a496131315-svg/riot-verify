ARAM Insight

A statistics and reference companion for ARAM and ARAM: Mayhem players.

About

ARAM Insight is a lightweight companion tool that helps players make better in-game decisions in ARAM (All Random All Mid) and its featured mode, ARAM: Mayhem. It presents champion statistics, augment references, and recommended builds in a concise, single-card layout designed for phone screens.

The product's particular focus is ARAM: Mayhem, where players choose from a large pool of augments. ARAM Insight helps them understand what each augment does and how it is generally performing, so that newcomers are not overwhelmed by the mode's complexity.

Riot Games APIs Used

Limited to the Standard APIs. No Tournaments API access is requested.

Match-V5 Account-V1 Summoner-V4 LoL-Status-V1

How It Works

  • All companion content is generated from aggregate statistics computed over match data.
  • Only aggregated statistics are stored — no raw match data is retained.
  • API keys are held server-side inside a cloud function environment and are never exposed to any client.

Delivery

ARAM Insight is delivered as a WeChat Mini Program, serving players on overseas servers, including Chinese-speaking players who play on overseas servers. It is a free, non-commercial tool — there are no paid features, no advertising on API-derived content, and no betting or gambling functionality of any kind.
